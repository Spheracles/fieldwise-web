# 田序共創｜FIELDWISE 網站（第四版）

從高雄大樹出發，陪小農整理經營、推廣產地好物，連結產地體驗與企業合作。

- 線上網站：https://spheracles.github.io/fieldwise-web/（GitHub Pages 從 `main` 分支的 `/docs` 發佈）
- 視覺與互動依交接包「00-網站設計與互動總覽」與第三版網站整併，並套用最新首頁方向。

## 怎麼修改

```
site/
├─ index.html        頁面骨架（各區塊標題與容器）
├─ styles.css        全站樣式：色票、粗黑體、實色圓角按鈕、正方形拼磚、斷點
├─ js/data.js        所有內容與設定：服務、方案價格、商品、文章、FAQ、法律頁、Google 表單對應、聯絡方式
├─ js/mosaic.js      首頁拼磚（三種欄數版型、大圖塊、四個入口、翻轉）
├─ js/app.js         首頁互動（服務、需求整理、故事影片、支持分頁、商品專區、方案、流程、資源、FAQ、對話框）
├─ js/contact.js     聯絡表單與 Google 表單送出
├─ js/views.js       #client-demo #admin-demo #privacy #terms #disclaimer 獨立畫面
├─ js/icons.js       Logo 與 12 個品牌雙色圖示
├─ assets/           內嵌圖片：定稿插圖（WebP）與 8 張商品圖
├─ public/           favicon、App 圖示、manifest、影片（直接複製到輸出資料夾）
└─ build.mjs         產生單一檔案網站
docs/                建置結果（GitHub Pages 發佈的檔案，請勿手動修改）
legacy/react-mvp/    第一版 React MVP 原始碼（保留備查）
```

修改 `site/` 內的檔案後執行（只需要 Node.js，不用安裝套件）：

```bash
node site/build.mjs
```

會重新產生 `docs/index.html`。這個檔案內嵌了樣式、程式與圖片，可以直接雙擊離線開啟；只有情境影片放在 `docs/media/`，離線開啟單一檔案時會改顯示插圖。

### 常見修改

| 想改什麼 | 改哪裡 |
|---|---|
| 商品名稱、介紹、製作流程、價格、狀態 | `js/data.js` → `PRODUCTS`；`price: null` 會顯示「價格試算中」 |
| 陪跑方案價格 | `js/data.js` → `PLANS`（季繳為 3 個月總額，節省金額自動計算） |
| 聯絡方式 | `js/data.js` → `SITE.contact` 填正式資料，再把 `contactTestMode` 改成 `false` |
| Google 表單欄位 | `js/data.js` → `SITE.googleForm.fields`；`enabled: false` 只產生本機摘要不送出 |
| 首頁拼磚版型 | `js/mosaic.js` → `LAYOUTS`（10／7／4 欄三種版型） |

## 已完成（對照交接包驗收清單）

- 首頁依最新方向：大標「把土地的美好 帶進每一天」（不含標點）、副標、荔枝／玉米／鳳梨大圖塊、01 當季農產／02 產地故事／03 食農體驗／04 最新消息四入口，保留「我是小農」「我要支持小農」雙入口。文字與按鈕皆為 HTML，可點擊與鍵盤操作。
- 正方形拼磚：依實際容器寬度計算欄數與格高，390、820、1280、1440px 下單格寬高差為 0；大圖塊以整數格合併；每 1.5 秒翻轉一格（0.8 秒），可暫停，遵守系統減少動態設定，頁面隱藏時停止。
- 四入口行為：01 跳到商品專區並選取「當季鮮果」、02 到我們的故事、03 到支持小農並切換「走進產地」、04 到最新消息（目前顯示「尚無正式消息」，沒有拿專欄文章冒充新聞）。
- **商品專區**：8 項鳳梨商品，分類篩選、商品卡、詳情對話框（這是什麼、來自哪裡、怎麼製作、怎麼吃、保存與配送）、「詢問此商品」自動帶入聯絡表單。價格只顯示試辦企畫書列出的建議測試售價（果乾 NT$150–190、果醬 NT$180–220），其餘顯示「價格試算中」；不提供購買按鈕，也沒有加入付款相關文案。
- 六項服務原地展開、需求整理多選、支持小農三分頁（方向鍵／Home／End）、三種方案月季切換與節省金額、比較表與單次專案、三個模擬情境、五階段流程（捲動固定場景，0／25／50／75／100%，按鈕可直接切換並暫緩自動切換約 2 秒）、工作台介紹、資源專欄分類與文章對話框、FAQ 逐項與全部展開。
- 聯絡表單：姓名必填、公司或農場選填、聯絡方式必填（Email、電話或 LINE ID）、五個可複選主題（未選時提示並聚焦第一個選項）、補充需求必填、個資告知同意；先整理成可複製的摘要，確認後送到 Google 表單。
- 保留：農場情境影片（AI 生成標示、滑鼠移入才顯示按鈕、自動播放兩次）、農友／團隊工作台示範、隱私權政策／服務條款／免責聲明草稿、favicon 與品牌圖示、聯絡方式測試模式。
- 定稿插圖沿用交接包原圖（轉為高品質 WebP 減少檔案大小，未改動畫面），以 SVG viewBox 顯示六格插圖中的單格，保持正方形不拉伸。

## Google 表單對應

網站的新表單比原本精簡，沿用同一份 Google 表單，對應到其中 7 題：

| 網站欄位 | Google 表單原題目 | 建議改名 |
|---|---|---|
| 怎麼稱呼你 | 姓名／稱呼 | 不用改 |
| 公司或農場名稱 | 單位／農場名稱 | 不用改 |
| 你的聯絡方式 | Email | 聯絡方式 |
| 想聊哪件事 | 主要問題 | 想聊的主題 |
| 詢問項目（自動帶入的方案、商品或服務） | 有興趣的方案 | 詢問項目 |
| 說說你的想法 | 補充說明 | 不用改 |
| 個資同意時間 | 個資同意時間 | 不用改 |

其他題目（角色、電話、服務區域等）之後會是空白，可以保留或刪除；**刪除或新增題目後要重新取得「預先填入的連結」並更新 `SITE.googleForm.fields`**。

## 示範與待辦

- 商品、產地體驗、合作夥伴為規劃示意；正式售價、規格、供應、配送與退換貨規則確認後再公告。
- 工作台畫面、模擬案例、資源文章為示範或內容範例。
- 聯絡方式目前為測試資料；LINE 官方帳號申請後填入 `SITE.contact.lineUrl`。
- 法律頁為草稿，正式上線前請律師審閱；公司名稱、統一編號與商標查核待補。
- 商品圖與情境影片為 AI 生成的示意素材，正式公開前建議換成實際拍攝的商品與產地照片。
